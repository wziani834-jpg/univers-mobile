# Conversation Logs

Ce dossier sert à archiver des résumés courts des échanges terminés.

Convention recommandée pour les fichiers :

`YYYY-MM-DD-sujet.md`

Exemples :

- `2026-04-28-bmad-method-diagnostic.md`
- `2026-04-28-site-homepage-review.md`

Contenu recommandé pour chaque note :

- contexte
- problème ou objectif
- décisions prises
- actions réalisées
- prochains pas

But :

- garder une trace claire de ce qui a été décidé
- retrouver rapidement le fil d’une session
- éviter de perdre les diagnostics ou les consignes importantes
